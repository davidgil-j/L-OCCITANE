# app/

Rutas de Next.js (App Router). Cada carpeta dentro de `app/` es una ruta;
de momento solo hay una página (`page.js`), la landing única de L'Occitane.

- `layout.js` — estructura HTML común (head, metadatos, fuentes)
- `page.js` — composición de la landing a partir de las secciones de `components/sections`
- `globals.css` — estilos base y directivas de Tailwind

No metas aquí componentes reutilizables ni contenido — eso va en
`components/` y `content/` respectivamente.
