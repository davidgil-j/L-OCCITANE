# design/references/

Capturas de pantalla y salidas de SkillUI (`skillui --url https://www.loccitane.es`)
usadas como referencia de estilo. No se publican ni se importan directamente
en el código — son solo inspiración para decidir los tokens de `../tokens/`.

`skillui-loccitane/` — el crawl automático contra es.loccitane.com fue
bloqueado por la protección anti-bot del sitio ("Access is temporarily
restricted"), así que sus DESIGN.md/tokens no reflejan la web real (ver
`skillui-loccitane/screens/pages/home.png`). Los valores reales en
`../tokens/` se estimaron visualmente a partir de capturas del sitio, no de
esta extracción.
